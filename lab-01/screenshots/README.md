## Aim
To create a web server using Node.js HTTP module and Express.js.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- Visual Studio Code

## Installation
1. Install Node.js.
2. Initialize the project using npm init -y.
3. Install Express using npm install express.

## How to Run

### Node.js Server
node server.js

### Express Server
node app.js

## Express Routes

| Route | Description |
|---|---|
| / | Home page |
| /about | Student details |
| /time | Current date and time |
| /anything | 404 error page |
